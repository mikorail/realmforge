# Realmforge

Procedural fantasy (and any-punk) world generator + living-world simulator. Inspired by Azgaar's Fantasy Map Generator (Voronoi pipeline) and Fantasy Map Simulator (watch / play god / play a person). Sibling of `four-seas` and shares its toolchain. Fully client-side, no backend.

## Stack
SvelteKit 3 + Svelte 5 runes + TS, `adapter-static` (SPA, `ssr=false`). Only runtime deps: `d3-delaunay` (Voronoi), `simplex-noise` and `fflate` (save compression), plus `@fontsource/*` fonts. Rendering is plain Canvas2D: static terrain is rasterised into cached tiles, everything else is cached `Path2D`s (no WebGL/Pixi). Generation runs in a Web Worker; the sim runs on the main thread.

## Run
- Node: system node v21 is too old; every npm script goes through `scripts/run-with-nvm.sh` (nvm v24). Dev: `npm run dev` or `scripts/dev.sh`, port **5180** (strict). Preview config "realmforge" is in parent `claude-projects/.claude/launch.json`.
- `npm test` (vitest: determinism, layers, spheres, features, 100-year 2-planet sim) · `npm run check` · `npm run build`.
- Headless: `npx tsx scripts/gen.ts [template] [cells]` (gen stats), `npx tsx scripts/sim.ts [years] [genre] [planets]` (chronicle + realm stats). Use these after touching gen/sim.
- Balance guards (2026-10-14): uprisings are budgeted (`scale = 10 / alive realms`, per-realm cooldown `sim.unrestUntil`, routine riots folded into one yearly digest); living cast capped at `150 + 6 × realms` (`pruneMinorPeople`); `allEvents` drops routine kinds older than 60 years past 25k entries (`compactArchive`). Innovation goes through `gainInnovation()` (×0.16) so eras arrive ≈ years 60 / 190 / 390 / 500+; god powers and player deeds add full value. `opts.evolve` makes `sim.voice` (narration genre + map/UI theme) follow the era; final age forks cyberpunk vs solarpunk on stability/wars.
- Perf baseline (2026-10-13): gen 10k cells ≈ 0.45s, 40k ≈ 0.95s, 100k ≈ 3.4s (node); sim ≈ 2ms/month @10k, ≈7 to 10ms @40k to 100k. Points go up to 200k.
- Sim perf after indexes (2026-10-14, node): `scripts/sim.ts 300 fantasy 2` (6k cells) ≈ 2.4s (was 6.4s); 100k cells, 60 years, 2 planets ≈ 5.8s (was 25.8s).
- Never `Math.max(...bigArray)`: spreading ~100k items overflows the browser call stack (node tolerates it, so tests won't catch it). Use `maxOf()` from `rng.ts`.

## Imports
Node subpath imports like four-seas: `#lib/*` → `src/lib/*.ts`, `#lib/components/*` passes through. Inside `src/lib` use relative imports (also needed for tsx scripts). The worker is loaded via `new URL('../gen/worker.ts', import.meta.url)`.

## Layout
- `src/lib/rng.ts`: seeded mulberry32 (`makeRng(seed|state)`, `.state()` for saves).
- `src/lib/share.ts`: URL hash encoding and decoding for one-click shareable seed links.
- `src/lib/export.ts`: Cartographer Studio (poster PNG rendering with cartouche/neatline/compass/scale bar, layered SVG maps, Markdown gazetteer dossiers).
- `src/lib/gen/` (pure TS, no DOM; runs in worker + node)
  - `options.ts`: `DEFAULTS`, `withDefaults()` (every entry point accepts a partial `GenInput`), `Climate` helpers (`latRange`, `lonRange`, `tempAt`, `windBand`, `kmPerPx`), `PLANET_CLIMATE`, `CLIMATE_PRESETS` (Whole world/Northern/Tropical/Southern), `SPHERE_SETS` (European/Asian/African/American/Oceanic/Silk Road/Global South/Eldritch), `DEFAULT_WINDS`.
  - `types.ts`: `GenOptions` (map w×h, cells, states, cultures, burgs, religions, sizeVariety, growth, seaLevel, rivers, layer density, `climate`), `World`, struct-of-arrays `Cells` (typed arrays, CSR neighbours/polygons), `Edges` (voronoi edges w/ vertex ids for smooth borders), `Layer` (kind surface/deep/sky/sea, `open` mask, own `state` array; **layer 0 `state` is the same array as `cells.state`**).
    - `species.ts`: 12 distinct fantasy and exotic races (Human, Elf, Dwarf, Orc, Troll, Beastman, Halfling/Gnome, Giant, Goblin, Dragonborn, Merfolk, Starborn Celestial) with stat modifiers, lifespan multipliers (elves 3.5x, dwarves 2.0x, celestials 5.0x, giants 4.0x), biomes, preferred layers, and polity forms.
    - `religions.ts`: 5 theologies (`THEOLOGIES`: monotheism, polytheism, animism, pantheism, dualism) and 7 doctrines (`DOCTRINES`: caste, evangelical, militant, compassion, liberation, esoteric, ancestral) with clergy titles and rites (`assignReligionIdentity`).
    - `grid.ts` jittered grid → Delaunay/Voronoi, `Heap`, `findCell`. `heightmap.ts` Azgaar-style template DSL (hill/pit/range/trough/strait/mask/smooth/noise); blob heights must be floored (that is what makes blobs decay). `physical.ts` features, climate from `Climate` (equator/pole temps, map's latitude band, altitude lapse), precipitation swept per wind band (6 bands, configurable angles), priority-flood rivers, `BIOMES` (13 Azgaar + Ashland/Crystal/Fungal/Lava), `PLANETS` modifiers, population.
    - `spheres.ts`: 22 culture spheres (Sinic, Japonic, Indic, SE Asian, Steppe, Persianate, Semitic, Sahelian, Guinean, Bantu-Swahili, Ethiopic, Nahuan, Mayan, Andean, Turtle Island, Boreal, Oceanic, Nordic, Celtic, Latinate, Slavic, Eldritch): phonemes, syllable structures, place affixes, polity forms, ruler titles, faith patterns, biome/climate affinity, and `grammar: NameGrammar` (surname kind house/patronymic/father/clan/none, patronymic markers, family-first order, clan pool size, house affixes + feminine forms, Akan-style day names, head-first compounding, epithets).
    - `names.ts`: O'Leary-style naming languages, sphere-aware; public API for everything in `naming/`. `makeName(L, key)` (city/land/river use the semantic dictionary 40/35/50% of the time, combined with sphere affixes; houses get grammar house affixes), `personName(L)` (single given name, drawn from a popular-name pool so lineages repeat names), `fullPersonName(L, sphere, opts)` → `{given, house, surname, epithet, plain, full}` (`house` stays the hereditary lineage for `Person.house`; `surname` is what the sphere shows). Languages built with a `:sim` seed suffix share the base culture's inventory, dictionary and clans. Determinism: dictionary/clans/day names use a side rng (`seed + ':lex'`), so they never shift the name stream.
    - `naming/`: `core.ts` (`Lang`, syllable/morpheme/word/spell, `joinAffix` elides seam vowels), `lexicon.ts` (36 `MEANINGS`, `buildLexicon`, `semanticBase`, `gloss`/`glossText` ("kal 'white' + vik 'ford'"; falls back to decomposing names into dictionary roots), `dictionary`), `grammar.ts` (`givenName`, `feminize`, `dayName`, `clanOf` (hash of house, so clans are hereditary), `patronym`, `epithet(rng, traits, sphere)`, `regnalName`, `toRoman`, `nextRegnalNumber`), `drift.ts` (pure `driftName(name, lang, centuries)` / `driftStages`; per-language sound-change subset, cumulative), `quality.ts` (`wordIssue`/`nameIssue`: ≤12-letter words, consonant needed, no 3+ vowels / 4+ consonants / triple letters, onset + coda allowlists, ugly letter pairs, one apostrophe per word (`tidy`), slur/obscenity blocklist, near-duplicates within edit distance 1 against the culture's place names).
    - `genre.ts`: 8 genres (fantasy, mythic, steampunk, dieselpunk, atompunk, cyberpunk, biopunk, solarpunk): polity forms + bias, settlement kinds per layer, layer names, layer density, vocabulary (`terms`), accent.
    - `society.ts` cultures/burgs/states/religions/routes (Dijkstra `expand`, A* roads + sea lanes, burg `links` graph). Use Float64 cost arrays (Float32 rounding broke expansion once).
    - `layers.ts`: exotic planes via 3D noise: deep levels (L1 under mountains, deeper sprawl even under sea), sky isles, sea shelves; each gets own cultures, faiths, settlements, realms, internal routes (tunnel/sky/sea) and vertical `shaft` links to the level above.
    - `universe.ts`: N planets (planet 0 = chosen options, rest rolled) + `rifts` between burgs of different planets. `worker.ts` posts progress + the `Universe`.
  - `src/lib/sim/`
    - `engine.ts` `Simulation` (one per planet): the state holder (people, polities, wars, archive, wonders, monsters, quests, `lb[layer]` = burg id per cell per layer, `bl[burgId]` = layer index), shared helpers (`crown`, `ruler`, `general`, `strength`, `atWar`, `warsOf`, `rel/addRel`, `neighborsOf`, `recount`), `tick()` (monthly) / `yearly()` orchestration, `updateVoice`, `skipMonths`, `dump()/restore()` for saves, and thin delegating methods so the public API (`sim.act`, `sim.cast`, `sim.declareWar`, `sim.log`, `sim.kill`, ...) is unchanged. Re-exports `POWERS` and `Power`. Behaviour lives in `systems/` as free functions taking `sim` (same pattern as `uprisings.ts`, `consolidation.ts`):
      - `systems/history.ts`: `log` (re-skins through the genre voice, keeps `events` ≤600 + unbounded `allEvents`), 5-year `takeHistorySnapshot` (`historySnapshots` up to 1000), `compactArchive`.
      - `systems/economy.ts`: demographics, treasury/army/stability economics, `innovate` (eras, discoveries, `applyTechBonus`), wonder upkeep, AI wonder and tower construction.
      - `systems/diplomacy.ts`: `computeBorders`, relations and alliances, AI war declarations (`aiWars`, `declareWar`), `endWars`, `finishWar` (peace, vassals, post-war constitution imposition on decisive defeat).
      - `systems/warfare.ts`: `monthlyWars` (cell-by-cell fronts on every layer + raids through shafts), `takeCell` (sieges, relic looting, wonder sacking), `relocateCapital`, `fall`, army regiment tokens.
      - `systems/lifecycle.ts`: `makePerson`, ageing/death with species lifespan scaling, heirs and generals, `kill` (succession, interregnum crown abolition, heirless claimants, avatar continuation), `pruneMinorPeople`, luminaries.
      - `systems/faith.ts`: faith spread, state conversion, heresies, The Great Reformation.
      - `systems/realms.ts`: `rebellions`/`revolt` (splits a realm with ideological motives: republican, agrarian union, burgher league, zealot rising), `colonize`, tribes, `foundState`, yearly random events (golden ages, famine, fire, plague, omens, palace coups).
      - `systems/environment.ts`: `seedPlague`/`spreadPlague`, `terraform` (water bodies/biomes after terrain edits), `reclimate(climate)` = live Configure World (temp/rain/biomes recomputed, populations rescaled, borders kept).
      - `systems/yearly.ts`: thin yearly bridges into politics, intrigue, ecology, pantheon (patron deities, Divine Proxy Wars), quests, AI monster hunting expeditions, uprisings.
      - `systems/godpowers.ts`: `POWERS` (25 powers across 4 spheres: Grace & Destiny, Earth & Genesis, Chaos & Calamity, Cosmos & Apocalypse, incl. Crown Chosen Realm `patron`), `canCast`, `cast(power, cell, layer)`, `castRandom(power, layer)`.
      - `systems/avatar.ts`: `choose`, `route()` Dijkstra over links, travel, encounters (`content.ts` + genre decks), `resolve`, `apply`, and `act()` (work, adventure, train, trade, research, preach, terrorize, scourge, audience, raise revolt/found realm, coup, revolutions, republics/unions/monarchies, riots, cults, prophecies, folk hero, markets, enterprises, infiltration, beast hunts, towers, wonders, secularize, ruler diplomacy, abdicate).
    - `indexes.ts`: incremental lookups, all keeping original array order so results stay byte-identical. `FrontIndex` (`sim.fronts`): contested edges on every layer bucketed by realm pair, synced once per war month by diffing layer state/open arrays, re-keyed by `takeCell`. `SimIndex` (`sim.idx`): `living(people)` (exact, lazy), `inState(people, id)` / `burgsIn(burgs, id)` candidate lists (re-check `alive`/`state` on read); **any new code that writes `person.state` or `burg.state` must call `sim.idx.touch()`**. `cellsByState` CSR (economy, faith), `OpenCells` (recount).
    - `cosmos.ts` `Cosmos`: ticks all planets in lock-step, fast-forward complete simulation (`completeSim`), rift colonies and cross-planet vanguard invasions, dynamic `tearRift`, `stepThrough` moves the avatar between planets. `skipMonths` routes through Cosmos so planets stay in sync.
    - `uprisings.ts`: spontaneous societal uprisings and unrest (`processYearlyUprisings`): riots (bread, tax, conscription, sectarian), secret cults (doomsday, eldritch, blood coven, flagellants), charismatic prophets, folk heroes and popular champions, garrison mutinies, and narrative generators.
    - `pantheon.ts`: 8 cosmic deities across celestial domains (Solarius, Kaelok, Nerida, Vaelith, Ilyra, Zephyros, Thalor, Morvath), patron realm assignment (`assignPatronDeity`), domain miracles, and Divine Proxy Wars (`processPantheonInterventions`).
    - `politics.ts`: 7 ideologies (`IDEOLOGIES`: monarchy, republic, theocracy, oligarchy, autocracy, communal, technocracy), internal faction generation (`generateFactionsForPolity`), influence/militancy dynamics, dynamic titles (`formatRegimeTitle`), regime transitions (`transitionRegime`), palace coup d'état simulation, peaceful constitutional reforms, popular mass revolutions, and State Atheism / revolutionary secularization (`updatePolitics`).
    - `ecology.ts`: Anthropogenic ecological catastrophes (`processAnthropogenicDisasters`): clearcutting wildfires, canal/dyke collapse floods, deep mine fissure cave-ins, over-farming dust bowls, runaway arcane leyline meltdowns, and reservoir dam ruptures.

## Conventions
- Panels receive the (non-reactive) sim plus a `v` counter; every `$derived.by` must read `v`. Don't use `(v, x)` comma tricks; svelte-check rejects them. A derived that returns the *same* object (e.g. `me`) won't re-render templates reading its fields: wrap those sections in `{#key v}`.
- Narration text should come from a genre pack or pass through `log()` (which re-skins). Sphere/genre content lives in data files (`genrepacks.ts`, `spherelore.ts`), not in engine logic.
- Commit after each feature; the repo had no commits until 2026-10-14.
- Keys: Space pause, 1 to 5 speeds, F fit, Esc cancel power.
- Roadmap / ideas: `ROADMAP.md`.
